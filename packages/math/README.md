# @patina/math

Linear algebra and accelerated geometry queries. ESM source package, version 0.1.0.

## Public API

`normalize`, `dot`, `cross`, `sub`, `add`, `scale`; `identity`, `multiply`, `perspective`, `lookAt`, `invert`, `transform`; `rayTriangle`, `OrbitCamera`, `BVH`.

## Host contract

Works in Node and browsers. Column-major matrices; right-handed camera and WebGPU 0–1 clip depth.

No application-module dependency. See the root docs/ARCHITECTURE.md for data layout, lifetime and backend-selection contracts. These archives are local distribution packages, not a claim of npm publication.
